# AZOJ
This is a simple OJ.Use SpringBoot.


┌─────────────────────────────────────────────┐

│                  Azoi OJ                    │

├──────────┬──────────┬──────────┬────────────┤

│  用户系统 │  题库系统 │  评测系统 │  竞赛系统   │

├──────────┼──────────┼──────────┼────────────┤

│ 注册/登录 │ 题目列表 │ 提交队列 │ 比赛列表    │

│ 权限管理 │ 题面展示 │ 判题机   │ 赛制支持    │

│ 个人主页 │ 标签分类 │ 评测结果 │ 排行榜      │

│ 团队/班级 │ 题目集   │ 重测     │ 封榜/解封   │

│ 封禁管理 │ 题解讨论 │ 沙箱     │ 赛后重测    │

└──────────┴──────────┴──────────┴────────────┘

用户提交
↓
后端 Service：
1. 存 Submission（status=Pending）
2. 推 submissionId 到 Redis List
3. 立即返回 submissionId
   ↓
   判题机（独立线程）：
1. 从 Redis List 拉 submissionId
2. 判题
3. 回写 Submission.status
   ↓
   前端轮询 / WebSocket 拿结果
